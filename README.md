# ❤️ CardioAI – Heart Disease Risk Prediction

CardioAI is an AI-powered machine learning application that predicts the risk of heart disease using patient health parameters.

## Features

- Heart disease risk prediction
- XGBoost machine learning model
- Interactive Streamlit interface
- Real-time prediction
- User-friendly dashboard

## Technologies

- Python
- Streamlit
- Pandas
- Scikit-learn
- XGBoost
- Joblib

## Input Parameters

- Age
- Sex
- Chest Pain Type
- Resting Blood Pressure
- Cholesterol
- Fasting Blood Sugar
- Resting ECG
- Maximum Heart Rate
- Exercise-Induced Angina
- Oldpeak
- ST Slope

## Project Files

```text
app.py
XGBoost_heart.json
scaler.pkl
columns.pkl
requirements.txt
README.md
```

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
